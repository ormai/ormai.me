Style and design

At the moment, this website is a collection of HTML and CSS files that I edit directly in a text editor. Just HTML and CSS can bring you far enough. The most recent developments like the addition of the <dialog> element are promising. I also try not to make each visitors download external fonts, as the device itself should already have them. Lastly I strive to have cool URIs, and you should too because it's very annoying when I bookmark your site and then I am met with a 404 error page.

Privacy and cookies

As a principle, this website doesn't set third-party cookies or runs code for analytical purposes. Your browser is basically downloading a bunch of files from my server and presenting them to you. Nothing is sent back. Both the Nginx access and error logs are bound to /dev/null.

Hosting and other services

This site is served via Nginx from my home by a minicomputer with an Intel Celeron J4105 and 8 GB of memory. I use the server to self-host various services such as FreshRSS at feed.ormai.me, a Forgejo instance at git.ormai.me, a CalDav/CardDav service with Radicale at ormai.me/radicale, and a Matrix home server with Continuwuity. The setup is pretty home-made, with the server being behind NAT and without a static IP address (I use a custom script for dynamic DNS).
